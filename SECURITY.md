# Security policy

Please do not post credentials, pairing codes, signing keys, private server addresses or private configuration in an issue.

Report a vulnerability through GitHub's **Security** tab using **Report a vulnerability**. Include the affected version, platform and reproduction steps, and redact personal data from logs and screenshots.

Public builds must be made from a clean checkout with `bash build.sh --generic`. Never publish `config.properties`, `freemytv.keystore`, or an APK built from private configuration.
